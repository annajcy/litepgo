# Generated API references

Use the manual to learn model construction and numerical conventions. Use the
references below to look up a constructor, method, option, or bound template
instance. Both are generated by `uv run docs/scripts/site.py build` and by the
development launcher before the site starts.

- <a href="./reference/cpp/index.html" target="_self">Open the C++ API reference</a>
- <a href="./reference/python/index.html" target="_self">Open the Python API reference</a>

## C++ reference

Doxygen scans `src/core/**/*.hpp`, excluding bindings and internal `detail/`
directories. It lists public declarations and provides source browsing. Many
headers currently use ordinary `//` comments, so descriptive prose is fuller in
the handwritten manual than in the generated symbol pages. Native template
signatures are visible independently of which Python instantiations are bound.

## Python reference

pdoc imports the selected compiled package. It documents public facade modules,
nanobind signatures/docstrings, and concrete FEM template instances. Platform
sparse backends and optional IPC Toolkit exports reflect that build. The
`litepgo.torch` module is always included; PyTorch is installed by `uv sync --locked`.

Build `litepgo_python` before generation to compile `_core` and register the Python
facades. An absent extension produces a build command;
an import from another checkout is rejected. The default package follows the
venv's `.pth` registration. To select a configured build explicitly:

```sh
PYTHONPATH=build/release/python uv run docs/scripts/site.py build
```

After changing bindings, rebuild `litepgo_binding` before regenerating. The generated
pages do not infer parameter bounds, physical units, or an equilibrium model
from a function name; those contracts are explained in the corresponding
[user-guide chapters](index.md#learn-a-model).

## Navigation and local output

The API references are standalone HTML applications with their own navigation
and search. They use full-page navigation, and the browser Back button returns
to the manual. Built files are under `docs/.vitepress/dist/reference/`; original
generated files are under `docs/public/reference/`. Both are generated artifacts,
not source files to edit.
